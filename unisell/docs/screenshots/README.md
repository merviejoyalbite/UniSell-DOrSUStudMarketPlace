## Capture notes

- The captures were taken from the Expo web preview with the JSON server running.
- The viewport was constrained to 390 px wide so the layout matches a narrow
  phone. Browser chrome and desktop margins were cropped out.
- The screenshots show seeded demo data, not test listings.
- If phone captures replace these, keep the same filenames so README links do not
  break, or update the main README at the same time.
- Do not describe web captures as “on-device” or “Expo Go” screenshots.
- **`01-welcome.png` is stale:** it predates the teal **Create an account**
  button. Recapture it on the phone pass before submission.
